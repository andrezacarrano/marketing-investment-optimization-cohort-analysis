## 🎯 Project Objective

Optimize marketing expenditures for the **Y.Afisha** platform by analyzing server logs, purchase data, and cost statistics.

The main objective is to evaluate the effectiveness of different marketing channels, analyze user retention behavior, and calculate profitability metrics (**LTV** and **ROMI**) to support strategic budget allocation decisions.

## 📊 Results

- **Engagement Metrics:** Calculation of DAU, WAU, and MAU to identify periods of peak user activity and average session duration.
- **Conversion Analysis:** Mapping the time required for users to convert from registration to their first purchase, identifying cohorts with the fastest conversion rates.
- **Channel Profitability:** Identification of marketing channels with the highest ROMI (Return on Marketing Investment) and lowest CAC (Customer Acquisition Cost).
- **Strategic Recommendation:** Development of a budget reallocation proposal focused on channels generating positive returns (LTV > CAC) and stronger long-term user retention.

## 🛠️ Tools & Technologies

- **Programming Language:** Python
- **Libraries:**
  - Pandas (data processing)
  - Matplotlib and Seaborn (data visualization)
  - NumPy (mathematical calculations)
- **Methodologies:** Cohort Analysis, LTV, CAC, and ROMI (Return on Marketing Investment) calculations.
- **Development Environment:** VS Code / Jupyter Notebook

## 📚 Skills Developed

- **Cohort Analysis:** Grouping users by their first purchase date to monitor purchasing behavior over time.
- **Business KPI Calculation:** Implementing calculations for cumulative LTV (Lifetime Value) and CAC by advertising source.
- **Conversion Funnel and Retention Analysis:** Evaluating user return frequency and identifying friction points in the purchasing process.
- **Financial Data Visualization:** Creating heatmaps to visualize cohort performance and stacked bar charts to represent cost and revenue distribution.

## 🚀 Future Improvements

- **Predictive LTV Modeling:** Applying regression algorithms to predict the future value of new customers based on their initial interactions.
- **Advanced Segmentation:** Analyzing cross-device purchasing behavior (Desktop vs. Mobile) to support more personalized advertising strategies.
- **Dashboard Automation:** Integrating the results into a BI tool (Tableau or Power BI) for real-time monitoring.
